# Deferred Cursor-native asset inventory

Only complete, file-only assets with a verified redistribution license and recorded provenance qualify for this plugin's vanilla Cursor surface. The installed bundle has three read-only specialists, one repository-authored implementation-discipline skill, one command, and one rule.

Migration from the uncommitted parity design is explicit: remove `/curiosity-coordinator`, `/curiosity-analyst`, `/curiosity-worker`, `/curiosity-generalist`, `/curiosity-implementer`, `/curiosity-engineering`, and the broad installed `/software-architecture` skill. Use the main Agent with native Explore/Plan and `/curiosity-deliver-change`; there are no backward-compatible aliases.

The following remain deferred pending separate need, license, provenance, overlap, and vanilla-native review: local AI-DLC bundles, security prompt suites, CLI integrations, MCP integrations, executable hooks, installers, generated agent collections, and any incomplete or unclear-license local asset. Tool-dependent assets do not qualify by merely removing their scripts; their behavior and claims require redesign and review. No deferred asset was copied or redistributed by this change.
