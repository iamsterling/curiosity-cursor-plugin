# ADR 0024: Native Todos are progress, not evidence authority

**Accepted evidence invariant, 2026-08-15; installed-surface assumptions superseded by [ADR 0026](0026-vanilla-cursor-native-orchestration.md), 2026-08-16.** Live Cursor CLI evidence showed an evidence Todo marked completed and `To-do All done` rendered after its required full test suite exited 1. Prompt instructions did not prevent the host/model presentation, so claims that failed evidence can keep native Todos from appearing complete are not supportable. The raw-evidence invariant remains current; the six-agent/writable/hook behavior referenced below does not.

Native Agent Todos are downgraded to attempted-work/progress projections. Evidence-command Todos say `execute <command> and capture exit/output`; a checked execution does not imply a passing outcome. After every execution or delegation, the parent performs a prompt-level Verification Gate mapping each mandatory requirement, scenario, and evidence command to raw PASS/FAIL/MISSING. Any FAIL/MISSING leaves the gate BLOCKED/UNVERIFIED and forbids finish confirmation regardless of Todo state or attempted user confirmation. Changing evidence requirements remains material drift requiring an updated native Plan and renewed native Plan acceptance.

Status reports the Todo projection and Verification Gate separately and calls out contradictions such as `All done` plus failed evidence. Children and advisors return raw evidence; the parent owns reconciliation. This is static/model-mediated guidance, not host enforcement. It adds no state, store, runtime, transcript parsing, OpenSpec/Beads implementation, or change to the inert hook, six-agent/seven-action surface, risk profiles, or handoff boundaries. No sanitized smoke report is committed in this change; that evidence awaits authorized retesting.
