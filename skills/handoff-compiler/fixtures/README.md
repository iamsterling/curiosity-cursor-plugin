# Acceptance fixture index

The focused test constructs these compact contracts directly so each mutation is visible beside its expected stable diagnostic:

- A: single-unit documentation/configuration correction with static parse evidence.
- B: behavioral bug with exclusive implementation/test ownership and red/green evidence.
- C: explicitly authorized independent read-only/write units, plus unauthorized mutation.
- D: sequential research evidence followed by integration ownership.
- E: blocking ambiguity with no proposal.
- F: read-only adversarial review input.
- G: ownership, dependency, context, criterion, policy, shape, completion, and schema failures.
- H: canonical serialization under reordered keys.
