name: goal-loop
description: Manage multi-turn work through an explicit goal contract and evidence checkpoints.
license: MIT
---

Use an explicit goal in the current conversation containing objective, binary acceptance criteria, non-goals, and required evidence. Record meaningful progress only after a completed phase. Pause and request input for blocking ambiguity. Report satisfaction only when each criterion has linked raw evidence; do not claim plugin-owned durability, continuation, lifecycle authority, or completion.
