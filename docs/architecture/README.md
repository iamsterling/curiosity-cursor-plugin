# Architecture

The current composition root retains completed agent routing and generic redacted capture only. Prompt/resource assets and the handoff compiler remain distribution resources; pure Ledger domain/archive modules remain non-runtime libraries.

The native side adds three read-only specialists, one implementation-discipline skill, one deliver-change command, and one always-applied rule. The main Agent edits and synthesizes; native Explore and Plan Mode provide discovery and consequential planning. It is file-only: no hook, MCP, automatic continuation, external runtime, installer, or lifecycle authority. The OpenCode foundation and `/loop-*` compatibility remain separate. See [`current-state.md`](current-state.md) and [ADR 0026](../decisions/0026-vanilla-cursor-native-orchestration.md).
