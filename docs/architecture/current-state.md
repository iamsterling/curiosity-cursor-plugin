# Current state

**Current (2026-08-15).** `iamsterling.curiosity-cursor-plugin` contains a research-phase OpenCode plugin foundation plus an additive native Cursor 0.3.2 surface. One OpenCode `Plugin.define` retains bundled-agent routing and generic redacted capture under `.opencode/curiosity-cursor-plugin/capture/v1/`.

The split still excludes the unfinished loop engine, Ledger lifecycle authority/runtime hooks/tools, graph proposal, typed engineering controllers, external records, local effects, and orchestration stub. `/loop-*` files remain markdown aliases; runtime requests fail closed with `CURIOSITY_CURSOR_COMPAT_RUNTIME_UNSUPPORTED`.

The native boundary is exactly six explicit markdown agents, one model-eligible `skills/curiosity-engineering/SKILL.md`, and one configured stop hook. Four agents are read-only advisors. Worker and implementer use `readonly: false` only for exact accepted, ready Todos with exclusive ownership. Native Todos are attempted-work/progress projections, not evidence authority. After execution/delegation, the parent maps mandatory requirements, scenarios, and evidence commands to raw PASS/FAIL/MISSING in a separate prompt-level Verification Gate. FAIL/MISSING blocks finish confirmation regardless of Todo checkmarks, `All done`, or attempted confirmation. Material drift still requires revised native Plan acceptance.

The stateless hook always emits `{}`. Common stop fields include `conversation_id`, `generation_id`, `workspace_roots`, and `transcript_path`, but they do not establish accepted Plan/Todo correlation; transcript parsing remains prohibited. The hook performs zero automatic follow-ups and does not count as translated behavior. `loop_limit: 5` is only a finite upper bound. There are no MCP servers, rules, commands, variables, plugin-owned workflow state, custom lifecycle runtime, OpenSpec/Beads implementation, installation, or marketplace metadata.

The Cursor and OpenCode surfaces coexist; no cutover occurred. Actual Cursor sessions require authentication. CWD is the default workspace; selecting this repository may load root `AGENTS.md` as a project instruction. Keep target and plugin roots distinct with `agent --workspace <target> --plugin-dir <plugin-root>`. Workspace trust may prompt and saved trust, account, and session state may persist. Omitting `--plugin-dir` rolls back plugin loading only.

Explicit agents are `/curiosity-coordinator`, `/curiosity-worker`, `/curiosity-implementer`, `/curiosity-researcher`, `/curiosity-reviewer`, and `/curiosity-strategist`; automatic selection is nondeterministic. `readonly: true` documents no file edits and no state-changing shell commands. It is not a confidentiality/no-read/local-only/no-network guarantee or proof of prompt compliance. Live CLI evidence showed Cursor marking an evidence Todo completed and rendering `All done` after the mandatory suite exited 1. Version 0.3.2 therefore makes no impossible prevention claim: static/model-mediated guidance requires a contradictory status report and blocked Verification Gate, but cannot control host rendering. The CLI surface is mostly exercised with partial results: F3 blocked finish correctly but did not self-flag semantic all-done state. The editor remains unverified because Orca Accessibility failed systemically. No complete runtime-parity claim is made.
